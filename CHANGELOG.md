# Changelog

## 1.1.0

- New controller layouts: **Wii Classic** (full controller with two sticks, L3/R3 and d-pad) and **Wii Remote**.
- Right stick support end to end (calibration, profile, virtual DS4, DSU server).
- Calibration wizard adapts to each layout; layouts with two sticks calibrate each one.
- English interface by default; Spanish available under Settings → Language.
- No default IP address; neutral wording for any DSU device.
- Simulator: `--control wii-classic | wii-remote`.

## 1.0.0

- First release: Left Joy-Con layout, guided calibration, profiles, virtual DualShock 4 with gyro at 250 Hz,
  optional Xbox 360 and DSU server outputs, simulator and test suite.
